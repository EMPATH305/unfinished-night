## 一、餘彩域的尺度

餘彩域沒有一張永遠正確的疆域圖。畫境內的石階、田畦與家門可以穩定存在，畫境之間的裂痕卻可能改變接合處。旅人的地圖因此至少要記兩件事：地方本身的路，以及上一次能抵達它的路。過期地圖不是毫無價值的廢紙，但不能用來保證下一班渡船會在同一處靠岸。

三地屬於目前可追查的「鹽路—鐘路—鏡岸」交通網，不代表彼此緊鄰，更不代表它們是世界盡頭。鹽市出口包裝鹽、修匣材料與借色服務；雪鈴城交換耐寒繩具、鐘件、冬季交通訊息及勘查工藝；玻璃潮汐提供船窗、反光板與沿岸航行經驗。普通工具仍有價值，世界不必每一樣東西都靠魔法運作。

淡水、食物、照護與工時不能被這些特產替代。鹽市缺水時不能只畫出更多交易；雪鈴城積案時不能只敲更大的鐘；玻璃潮汐失去渡路時不能只留下更美的未來。

裂痕通行需要勘查與維護。渡色者必須核對往返兩端、接收意願、補給和備用停靠處；守框人判斷開口對現有結構的負荷；拾遺者可提供過往路線片段，卻不能保證片段仍有效。三者因此有長期合作的必要，並非只在危機最後一刻才突然握手。

各地以本地融雪、潮位和市集週期計時。跨境事件先以同一張運單、同一支修工隊或可比對的信章排序，不急著建立能涵蓋所有畫境的統一年表。這使後續能增加遠方區域，也避免用日曆空白掩飾既有事件的矛盾。

## 二、歷史先後與尚未填滿的空白

可以確立的地方順序如下；三條順序之間目前不強行對齊年份。

- **鹽市**：伊蕾起筆與居民定居 → 短期代領制度 → 伊蕾離開 → 後來的供色短缺與代理權擴張 → 現在的十三戶借色爭議。開門救下三條街發生於目前之前，其與每一輪契約改制的先後尚待更多地方紀錄對照。
- **雪鈴城**：涅芙繪製雙視角城市 → 居民發展多來源聽證 → 涅芙離開 → 聽證簡化與封簿冬 → 現在的糧袋爭議。乾潮症狀的出現時間不與制度簡化直接畫上因果等號。
- **玻璃潮汐**：賽洛留下多種候景 → 工屋交由居民、畫者離開 → 居民逐步發展凝景技術 → 定帆協約由施工目標變為返岸宣傳 → 現在的航路與借色爭議。

三位原畫者不預設相識，不預設由同一場悲劇驅使，也不預設被共同反派帶走。未完稿造成的是材料、空間和習慣上的起點；後來的居民既能擴大其缺陷，也能修正它。找到原作者的心意，不等於找到全城必須服從的遺囑。

## 三、創作層知道，玩家未必知道

本卷中「原畫者」段落含創作背景，便於後續寫作保持一致；不應直接當成墨的全知說明。各地可以將它們拆成草圖、工程紀錄、私人信與相互不同的口述，讓玩家逐步確認。

| 知識層次 | 寫作方式 | 例子 |
| --- | --- | --- |
| 已確立的創作設定 | 作為後續作者共同遵守的底線 | 候景不是確定預言；姓名抵押不是奪魂術 |
| 當地可查證事實 | 指出物件、來源與比對方式 | 代名牌期限被改過；某鐘空場也會回響 |
| 人物的陳述 | 保留說話位置、時間與授權範圍 | 「我看見的那道門一直關著」 |
| 調查中的推論 | 附可反駁條件，不寫成揭曉 | 信匣可能參與過白鹽信的轉運 |
| 尚未定稿的空白 | 明示未定，不暗示已有唯一答案 | 第十三封信的寄件人、三位畫者的後來去向 |

墨能提出問題、承認不知道、保管願意交付的片段，也能拒絕新的負擔。牠不因進入第二部便升級為解讀所有物件的歷史播放器。寄憶不是復活，想念也不構成替缺席者回答的許可。

## 四、三地不同的倫理重心

赤赭鹽市問：**一個人答應了，是否真的有拒絕後還能生活的路？** 所以需要供水、替代方案與可撤回的授權。

雪鈴城問：**一個人沒有欺騙，是否就能描述整件事情？** 所以需要視角、校驗、修正程序，也要讓等待的人繼續生活。

玻璃潮汐問：**一個人真心盼望，是否就能要求別人完成？** 所以需要釐清願望的主人、資源的來源，以及退出承諾的方式。

三地不是同一道「選擇自由」題換三張背景。鹽市的關鍵在交換條件，雪城在知識限度，鏡岸在未來承諾。三者都需要具體勞動與協商，但不能用同一套收集三件物品後說服所有人的結局處理。

乾潮是橫跨畫境的觀察名稱，不是已證實的單一病原。借色來源、材料疲勞、天候與制度造成的負擔需分別調查。不把居民的悲傷、保守或想念寫成世界生病的罪因，也不讓角色只要接受改變就能免除修工、供水與照護。
