# 未乾之夜 · The Unfinished Night

以梵谷繪畫為靈感，與烏鴉「墨」一同探索的五章原創奇幻遊戲。

創作發起：林萱渝。故事、程式與繪畫素材：AI 協作。世界與情節均為虛構，非梵谷生平或畫作的唯一解讀。

## 遊戲內容

- 五幅可探索畫境：迴星鎮、岔路麥原、日葵庭、候歸之室、空白海。
- 每章兩個探索區域，共十個區域；保留原畫作，透過區域切換展開事件。
- 十道謎題、借色、二十五段記憶、每章選擇與三種主結局。
- 決定前要調查與準備；前四章決定後有必經回訪，終章會收到各地角色的回覆。
- 前四章的決定會改變尾聲；主要選擇共有 48 種組合。
- 滑鼠、鍵盤、手機點擊操作；本機自動存檔與 JSON 存檔匯出／匯入。

這是五章增補版。故事從原來的快速主線擴充為調查、準備、決定與回訪；實際通關時長仍需真人試玩測量，尚不承諾達到原先設想的 75–125 分鐘。

## 在 GitHub Pages 發布

本專案已整理成靜態網站的根目錄結構，不需要安裝套件、建置、API 金鑰或 AI 訂閱。

1. 將本資料夾的內容放在 GitHub 儲存庫根目錄，讓 `index.html` 與 `assets/` 直接出現在最外層。
2. 進入儲存庫 **Settings → Pages**。
3. Source 選 **Deploy from a branch**；Branch 選 **main**；資料夾選 **/(root)**；按 **Save**。
4. 等待 GitHub 完成發布後，使用 Pages 設定頁顯示的網址。

GitHub Free 的 Pages 適用於公開儲存庫；採用公開儲存庫時，遊戲原始碼與素材也可被瀏覽。

依據：[GitHub 官方 Pages 設定說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

本儲存庫已啟用 GitHub Pages：[開啟遊戲](https://empath305.github.io/unfinished-night/)。上述步驟供複製專案到其他儲存庫時使用。

## 在電腦離線玩

下載並解壓縮完整專案，直接以瀏覽器開啟 `index.html`。必須保留旁邊的 JavaScript、CSS 與 assets 資料夾，不要只傳一個 HTML。

先從畫面上方選擇本章區域，點地標即可移動並對話。長對話每兩段一頁，最後一頁才顯示操作。也可使用 WASD／方向鍵，靠近地標後按 E。手機可點地標或使用右下方向按鈕。問問墨、旅人手記與謎題內的「重讀線索」提供提示。

## 存檔與換網址

進度儲存在當前瀏覽器的 localStorage。GitHub Pages 與原本的線上版網址不同，存檔不會自動互通。

從舊版的「旅人手記 → 下載旅程存檔」，再到 GitHub 版選「匯入旅程存檔」，就能接著玩。無痕模式、瀏覽器儲存限制、清除網站資料或移動本地檔案，都可能影響自動存檔；請保留匯出的 JSON。

## 舊旅程如何接續

舊存檔會保留當前章節的原流程，下一章才接入增補內容；已通關的舊結局仍可重讀。想體驗全部新事件，請先下載舊存檔，再開始新旅程。存檔格式已升級至 version 2，載入 version 1 時會先遷移再驗證；以 contentVersion 區分內容流程，保留既有章節、顏色、選擇與記憶。較新而尚未支援的格式會提示更新遊戲，不會改寫匯入檔案。

## 要改哪個檔案？

| 檔案 | 用途 |
| --- | --- |
| index.html | 選單、畫面骨架、按鈕與文字容器 |
| style.css | 色彩、排版、手機版與動態效果 |
| story.js | 章節名稱、地標、記憶資料與章節開場 |
| journey.js | 新事件、探索分區、額外謎題、章節銜接與回訪條件 |
| engine.js | 角色對話、解謎條件、分支與結局 |
| game.js | 操作、移動、畫面更新、環境音與存檔 |
| assets/ | 全部本地繪畫圖片 |
| WORLD_AND_HANDOFF.md | 世界觀、長期目標與後續交接 |
| WALKTHROUGH.md | 五章攻略，含劇透 |
| tests/progression.cjs | 劇情與存檔的自動檢查 |

不需要重做框架即可修改。後續改動存檔格式時，需同步提供版本遷移，保留玩家既有進度。

## 驗證狀態

已檢查 96 條完整增補路線（48 種主要決定 × 2 種手稿處理方式）、十個謎題、答錯恢復、分區導航、回訪前置條件、顏色歸還、二十五段記憶與存檔往返；六份更新前存檔也驗證能完成原章節並銜接新內容。若電腦裝有 Node.js，可執行 `node tests/progression.cjs` 重跑。

介面回歸測試位於 tests/ui-regression.mjs，從主選單實際操作第一章，檢查星空暫停、分頁、焦點、走路、提示可見性、兩段式線索與決定色調。GitHub Actions 會在 main 更新和 PR 時執行劇情、存檔與桌面／手機尺寸／減少動態的 Chromium 測試，並保存截圖。可在電腦執行 `npm install`、`npx playwright install chromium`、`npm test`、`npm run test:ui`。這些套件僅供開發測試，遊戲仍可直接開啟 HTML。

讀屏器實機、觸控裝置及真人遊戲節奏仍需另外驗收。選用的 WebMCP 讀取介面未在瀏覽器中驗證，不影響一般遊玩。

## 素材

場景與烏鴉是 AI 生成的原創後印象派風格插畫，不是梵谷原作數位複製品。音效由瀏覽器合成純音，字型使用裝置本地字型；無外部音樂、字型或 AI API 依賴。

## 畫面與提示

主選單的星空以現有天空紋理做局部旋轉，城鎮與標題固定；可用「暫停星空」停止，系統設定減少動態時也會靜止。這不是新的季節或光線背景圖。WASD 操作不再以大框包圍地圖，Tab 選取按鈕時仍有焦點標示。答錯訊息留在謎題內直到重設、解題成功或關閉對話，線索與錯誤區皆有禮貌報讀通知。
